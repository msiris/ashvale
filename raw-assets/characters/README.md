# 여기에 캐릭터 15장을 넣는다

`1.png` ~ `15.png` 를 이 폴더 **바로 아래**에 둔다.
하위 폴더로 한 겹 더 들어가지 않게 할 것.

넣은 뒤 `npm run assets` 를 돌리면 `public/assets/characters/01..15.png` 가 된다.

## 규격

각 파일: 64×96 PNG, 16×24 프레임 4열×4행, 알파 있음.
행 순서 0=아래 1=왼쪽 2=위 3=오른쪽. 상세는 `src/data/characters.ts`.

**규격에서 벗어나도 된다.** `scripts/copy-characters.ts` 가 맞춰 굽는다 —
배경이 흰색으로 칠해진 그림이면 바깥 흰 영역을 투명으로 만들고,
크기가 다르면 64×96 으로 줄인다. 확장자만 `.png` 인 JPEG 도 받는다.

규격대로 들어온 것만 바이트 그대로 복사된다. 처음 쓰던 CC0 팩은 투명 픽셀이
마젠타에 알파 0 이라 다시 인코딩하면 분홍이 드러나기 때문이다.

이 폴더는 팔레트 리맵에서 제외된다 (`scripts/remap-palette.ts` 의 SKIP).
