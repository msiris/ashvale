> 탑다운 픽셀 필드를 걸어다니는, 끝나지 않는 관계 중심 RPG.
> 구현 에이전트(Claude Code)에게 넘기는 것을 전제로 작성했다. 수치는 1차 밸런스 기준값이며 상수 테이블로 분리한다.
>
> **v2.1:** 캐릭터 스프라이트 시트 실측으로 §12 확정, 팔레트 충돌 해결(40색).
>
> **v1.5(거점 경영형)를 대체한다.** 저장·이미지·배포·문체 규약은 v1.5에서 검증된 것을 그대로 승계했고, 필드 이동·대화 시스템·관계 방향 전환이 새로 들어갔다. 몬스터 수집과 전투는 범위 밖이다.

## 1. 컨셉과 설계 원칙

변방의 개척지에 도착해 사람들과 관계를 쌓는다. 마을을 걸어다니며 인물을 만나고, 함께 지역을 탐사하고, 그 과정에서 마을이 자라고 새 사람이 모인다. **엔딩이 없다.** 시대가 갱신되며 인물과 지역이 계속 열린다.

### 원칙

1. **관계는 이쪽에서 파는 것이 아니라 저쪽에서 다가온다.**
   교류 버튼을 눌러 호감을 채우는 구조가 아니다. 함께 겪은 일이 호감을 만들고, 일정 수준을 넘으면 **인물이 먼저 말을 걸어온다.** 플레이어는 반응할 뿐이다. 이 방향이 장르 감각의 대부분을 결정한다.
2. **판정은 공개한다.** 주사위와 보정 계산식을 그대로 노출한다.
3. **캐릭터는 죽지 않지만 마을은 무너질 수 있다.** 붕괴해도 연대기와 업로드 이미지는 보존된다.
4. **성장은 걸으면서 보인다.** 건물이 새로 서고, 문이 열리고, 그 안에 사람이 있다. 수치판이 아니라 풍경이 바뀐다.
5. **두 축이 서로를 먹인다.** 탐사가 관계를 올리고, 관계가 새 지역과 새 인물을 연다. 한쪽만 파면 막힌다.

```
마을 산책 ──▶ 동행 요청 ──▶ 지역 탐사 ──▶ 사건과 성과
    ▲                                          │
    │                                          ▼
새 인물 합류 ◀── 관계 진전 ◀── 인물이 말을 걸어옴
```

## 2. 화면 구조

세 화면이 전부다. 이 구조를 늘리지 않는다.

| 화면 | 내용 | 시간 |
|---|---|---|
| **마을** | 걸어다니며 인물·건물과 상호작용. 안전 지대 | 흐르지 않음 |
| **지역** | 걸어다니며 사건 노드를 밟음. 탐사 | 나갈 때 1주 소모 |
| **대화** | 인물 이미지 + 대사창. 마을·지역 어디서든 전환 | 흐르지 않음 |

**마을에서 걷는 것은 시간을 소모하지 않는다.** 이동이 자원이 되면 걷는 재미가 벌이 된다. 시간은 지역으로 나갈 때만 흐른다.

### 화면 배치 (세로 393×852dp 기준)

```
┌─────────────────────────┐
│ 아쉬베일   1년 3주·봄   │  HUD 40dp
├─────────────────────────┤
│                         │
│      필드 (Phaser)      │  약 470dp
│      12×11 타일 가시     │
│                         │
├─────────────────────────┤
│  ↑         │            │
│ ← →   [A]  │  조작 180dp│
│  ↓         │            │
└─────────────────────────┘
```

대화 진입 시 필드 위에 대화 레이어가 덮인다. 화면 전체를 갈아끼우지 않는다 — 배경에 지금 서 있는 자리가 비쳐야 장소감이 유지된다.

## 3. 시간과 핵심 루프

- **1주 = 지역 탐사 1회.** 12주 = 1계절, 4계절 = 48주 = 1년
- 마을 활동(대화·건설·선물)은 시간을 쓰지 않는다
- 계절 보정: 봄 식량 +20% / 여름 목재·석재 +20% / 가을 식량 +50% / 겨울 식량 −50%, 지역 위험도 +20%

### 주 종료 처리 순서 (고정)

1. 탐사 결과 적용
2. 자원 생산 − 식량 소비 (계절 보정)
3. 회복 (신전 등)
4. 관계 갱신 — 호감 반영, **다가옴 판정**(§7.3)
5. 세계 이벤트 판정 (12%)
6. 시대 판정 → 해금 판정(지역·인물·건물)
7. 주차 증가, 연대기 기록
8. 자동 저장

## 4. 데이터 모델

```ts
type ResourceId = 'wood' | 'stone' | 'food' | 'gold';
type StatId = 'might' | 'agility' | 'insight' | 'will';
type FactionId = 'guild' | 'oath' | 'grove' | 'tower';
type Dir = 'up' | 'down' | 'left' | 'right';

interface GameState {
  schemaVersion: 1;
  createdAt: number;

  hero: {
    name: string;
    level: number; xp: number; hp: number; maxHp: number;
    stats: Record<StatId, number>;
    statPoints: number; skillPoints: number;
    skills: Record<string, number>;
    relics: string[];
  };

  town: {
    name: string;
    buildings: Record<string, number>;   // buildingId -> level (0 = 미건설)
  };

  resources: Record<ResourceId, number>;

  world: {
    year: number; week: number; turn: number;
    eraIndex: number; eraTier: number;
    unlockedRegions: string[];
    currentMap: string;                  // 'town' | 'region:whisper' | 'indoor:hall' ...
    heroTile: { x: number; y: number; dir: Dir };
  };

  companions: Record<string, CompanionRecord>;
  patrons: Record<string, PatronRecord>;
  factions: Record<FactionId, number>;   // -100..100

  escort: string | null;                 // 동행 중인 관계 대상 id
  pendingApproach: string[];             // 말을 걸어오려고 대기 중인 인물 (§7.3)

  chronicle: ChronicleEntry[];           // 최근 200개
  counters: {
    expeditions: number; buildsMade: number; collapses: number;
    confessions: number; firsts: Record<string, boolean>;
  };
}

interface CompanionRecord {
  id: string; archetypeId: string; name: string;
  affinity: number;                      // 0..100
  track: null | 'bond' | 'romance';
  confessed: 'none' | 'pending' | 'accepted' | 'declined';
  clearedEvents: string[];
  lastApproachTurn: number;
  injuredUntilTurn: number;
  images: Record<number, string | null>; // slot -> IndexedDB 키 (참조만)
  unlockedSlots: number[];
  homeRegion: string;
  origin: 'preset' | 'quest' | 'drifter' | 'referral';
  joinedTurn: number; departedTurn: number | null;
}

interface PatronRecord {
  id: string; met: boolean; trust: number;   // 0..60
  questsCleared: string[]; activeQuestId: string | null;
}
```

**구현 지침**

- 수치 테이블은 `src/data/*.ts` 상수로. 규칙 로직은 `src/systems/`의 순수 함수 `(state, input, rng) => { state, entries }`
- **시각 상태는 저장하지 않는다.** 맵 렌더 상태·NPC 스프라이트 위치는 `GameState`에서 파생한다. 예외는 `heroTile` 하나 — 이건 게임 상태다(어디에 서 있는지가 세이브의 일부)
- Phaser 씬은 `GameState`를 읽기만 한다. `syncFromState(state)` 한 곳에서 갱신
- RNG는 시드 주입 가능하게 감싼다

## 5. 이동과 조작

### 이동

- **그리드 기반 4방향.** 타일 단위로 이동하며 대각선은 없다
- 한 칸 이동 **140ms**, 그동안 입력을 큐에 하나만 쌓는다. 버튼을 연타해도 무너지지 않아야 한다
- 걷기 애니메이션은 **방향당 3프레임**(정지 / 왼발 / 오른발) 순환. 실제 프레임 수는 에셋에 맞춘다(§12)
- 방향 전환만 하는 경우: 정지 상태에서 다른 방향 입력 시 **첫 입력은 방향만 바꾸고 이동하지 않는다.** 벽을 보고 말을 걸 때 필요하다
- 카메라는 플레이어를 중심에 두고 따라간다. 맵 경계에서는 멈춘다

### 조작

| 입력 | 동작 |
|---|---|
| 좌하단 D패드 | 이동·방향 전환 |
| 우하단 A | 말 걸기 / 대사 넘기기 / 확인 |
| A 길게 | 대사 빨리 넘기기 (자동 진행 아님) |
| 상단 HUD 탭 | 메뉴 열기 (인물·마을·연대기·설정) |

- 화면 탭으로 이동하는 방식은 쓰지 않는다. 인물에게 말을 걸 때 좌표가 애매해진다
- 터치 타깃 최소 **44dp**. D패드 버튼은 46dp 정사각
- 물리 키보드(데스크톱)에서는 방향키 + Space/Enter를 같은 동작에 매핑한다

### 상호작용

- 플레이어가 **바라보는 칸**에 인물·문·표지가 있으면 화면 하단에 프롬프트를 띄운다: `A — 말 걸기`
- 프롬프트는 대상 종류에 따라 문구가 바뀐다: `말 걸기` / `들어가기` / `살펴보기` / `나가기`
- 인물은 밀어서 지나갈 수 없다. 통로를 막는 위치에 NPC를 두지 않는다

## 6. 맵 구조

### 맵 종류

| 종류 | 예 | 특징 |
|---|---|---|
| 마을 | `town` | 안전. 시간 안 흐름. 시대에 따라 확장 |
| 실내 | `indoor:hall`, `indoor:shop` | 마을 건물 내부. 인물이 상주 |
| 지역 | `region:whisper` 외 5 | 탐사 대상. 사건 노드 배치 |

### 전환

- **문(door) 타일**을 밟고 A → 대응 맵으로 전환. 페이드 220ms
- 마을 가장자리의 **길목(gateway)** → 지역 선택 화면 → 해당 지역 맵으로. **이 시점에 1주가 소모된다**
- 지역에서 `나가기`를 고르면 마을로 복귀. 추가 시간 소모 없음
- 전환 시 `world.currentMap`과 `heroTile`을 갱신하고 저장한다

### 맵 제작

- **Tiled 에디터**로 만들고 JSON으로 내보낸다. Phaser가 기본 지원한다
- 레이어 규약: `ground`(바닥) / `deco`(위에 겹치는 장식) / `collision`(충돌, 보이지 않음) / `objects`(문·NPC 배치점·사건 노드)
- 충돌은 별도 레이어로 관리한다. 타일 종류로 판정하지 않는다 — 나중에 타일셋을 바꿀 때 전부 깨진다
- 오브젝트에는 `type`(door/npc/node/gateway)과 `target`을 속성으로 넣는다

### 시대에 따른 마을 확장

| 시대 | 마을 크기 | 열리는 것 |
|---|---|---|
| 0 개척기 | 20×18 | 회관, 공터 |
| 1 정착기 | 20×18 | 목재소·농장 부지, 실내 1곳 |
| 2 성장기 | 28×24 | 북쪽 구역, 시장 골목 |
| 3 영주기 | 28×24 | 성벽과 문 |
| 4 왕국기 | 36×30 | 동쪽 구역, 항구 길 |
| 5 전설기+ | 36×30 | 첨탑 부지 |

- 맵은 시대별로 **별도 파일이 아니라 하나의 큰 맵 + 잠긴 영역**으로 만든다. 시대가 오르면 잠금이 풀리고 건물 오브젝트가 나타난다. 맵을 여러 벌 그리면 유지가 불가능해진다
- 잠긴 영역은 무너진 담·수풀 등으로 막고, 열릴 때 연출과 함께 치운다

## 7. 인물과 관계

### 7.1 두 명단

| | **관계 대상** | **의뢰인** |
|---|---|---|
| 성별 | 여성 | 남성 |
| 이름 | 플레이어 지정 | 프리셋 고정 |
| 이미지 | **플레이어 업로드**, 슬롯 6개 | 픽셀 스프라이트 + 원형 실루엣 |
| 수치 | 호감 0–100 | 신뢰 0–60 |
| 고백 | 있음 | 없음 |
| 역할 | 동행, 대화 사건, 갤러리 | **퀘스트 발행**, 신규 관계 대상 소개 |
| 상한 | 8명 | 6명 |

플레이어 1 + 관계 대상 8 + 의뢰인 6 = **15명.** 캐릭터 스프라이트 팩의 15종과 정확히 대응한다(§12).

### 7.2 원형 6종

이름과 얼굴은 플레이어가, 성격·대사·취향·고향은 원형이 제공한다.

| ID | 원형 | 소속 | 취향 | 고향 지역 | 동행 보정 |
|---|---|---|---|---|---|
| knight | 기사 | 은빛 서약 | 무구·석재 | 무너진 관문 | 위기 결과 HP 손실 −50% |
| hunter | 사냥꾼 | 숲의 부족 | 식량·가죽 | 속삭이는 숲 | 탐사 판정 +2 |
| mage | 마법사 | 마탑 | 유물·서적 | 지하 대공동 | 통찰 판정 +2, 유물 발견 +3%p |
| herbalist | 약초사 | 숲의 부족 | 씨앗·식량 | 재의 늪 | 탐사 HP 손실 −50% |
| envoy | 사절 | 은빛 서약 | 금화·예물 | 서리 봉우리 | 전리품 +20% |
| wanderer | 방랑자 | 없음 | 생성 시 무작위 | 별의 균열 | 무작위 (생성 시 고정) |

- **고향 지역이 §1 원칙 5의 연결점이다.** 그 인물과 관계가 깊어지면 고향 지역이 열리고, 그 지역을 탐사하면 그 인물의 호감이 더 오른다
- 같은 원형이 여럿이면 보정은 **중첩되지 않고 최대값만** 적용
- 대사는 `src/data/content/companion-dialogue.ts`(144줄) 사용. 새로 쓰지 않는다

### 7.3 호감은 어떻게 오르는가 — 다가옴 구조

**교류 버튼이 없다.** 호감은 함께 겪은 일에서만 오른다.

| 경로 | 획득 | 조건 |
|---|---|---|
| 동행 탐사 | 성공 +6 / 대성공 +12 / 실패 +3 / 위기 +1 | 주당 1명만 데려갈 수 있다 |
| 고향 지역 탐사 | 추가 +4 | 동행 여부 무관. 그 인물의 고향이면 |
| 선물 | 취향 일치 +12 / 불일치 +4 / 혐오 −3 | 인물당 4주 쿨다운 |
| 대화 사건 | 선택지에 따라 +8 / +4 / −2 | 다가옴으로만 발생 |

**다가옴 판정 (주 종료 처리 4단계)**

```
조건: 호감이 다음 단계 문턱을 넘었고, 그 단계의 대화 사건이 미소화 상태
   → pendingApproach 에 인물 id 추가
결과: 다음에 마을에 들어가면 그 인물이 플레이어 쪽으로 걸어와 말을 건다
```

- 플레이어가 찾아가는 것이 아니라 **인물이 다가온다.** 마을에 들어선 순간 스프라이트가 이쪽으로 이동하고 자동으로 대화가 열린다
- 대기 중인 인물이 둘 이상이면 호감이 높은 쪽부터 한 명씩. 한 번에 하나만 발생시킨다
- 무시하고 걸어가면 다음 마을 진입 때 다시 시도한다. 3회 무시하면 호감 −3과 함께 물러난다(그 사건은 다시 대기열로)

### 7.4 고백

**벗(60) 도달 후 다가옴 사건으로 자동 발생한다.** 플레이어가 고백하는 선택지는 없다.

| 응답 | 결과 |
|---|---|
| **수락** | 연심 트랙 진입. 이미지 슬롯 4 해금. 마을에 상주 위치가 생김 |
| **보류** | 관계 유지. 호감은 계속 오르고 **6주 뒤 다시 고백해온다.** 3회까지 |
| **거절** | 우애 트랙 고정. 호감 −10, 이후 연심 진입 불가. 소개 연쇄는 계속 가능 |

- **보류가 이 장르의 핵심이다.** 수락도 거절도 아닌 상태에서 인물이 계속 다가오는 것이 긴장을 만든다
- **연인은 여러 명 가능하다.** 질투 페널티는 없다
- 대신 우애 트랙이 죽지 않도록 **소개 연쇄(신규 인물 유입)를 우애 트랙 전용**으로 둔다. 맹우(우애 80)만 새 인물을 데려온다. 전원을 연심으로 밀면 로스터 성장이 멈춘다 — 벌이 아니라 기회비용이다

### 7.5 경쟁 사건 — 질투를 콘텐츠로

연인이 2명 이상일 때 발생하는 **2인 동시 사건.** 수치를 깎는 대신 상황을 만든다.

- 발생: 연인 2명 이상, 8주마다 1회, 무작위 2명
- 구조: 두 인물이 동시에 등장. 선택지 3개 중 하나는 한쪽 편, 하나는 다른 쪽, 하나는 중립
- 결과: 편든 쪽 +6, 반대쪽 −4 / 중립은 양쪽 +1 (가장 안전하지만 가장 적다)
- 전용 이미지 슬롯을 쓰지 않는다. 두 인물의 슬롯 0을 나란히 표시한다
- 원형 조합별로 사건을 따로 쓰지 않는다. **범용 사건 6개**를 쓰고 이름과 초상만 바꾼다. 조합은 28가지라 개별 작성이 불가능하다

### 7.6 의뢰인

전원 남성, 프리셋. 신뢰 0–60, 3단계(안면 / 거래처 20 / 오랜 벗 40).

| 이름 | 원형 | 등장 | 발행 퀘스트 |
|---|---|---|---|
| 바르텍 | 상인 | 시대 0 | 교역로 개척 → 관계 대상 1명 |
| 토바 | 장인 | 시대 1 | 채석장 증축 → 성벽 재질 해금 |
| 하를 | 대장장이 | 시대 1 | 서약의 시험 → 관계 대상 1명 |
| 오렌 | 서기 | 시대 2 | 고문헌 해독 → 지역 조기 해금 |
| 도란 | 촌장 | 시대 2 | 이주민 유치 → 관계 대상 1명 |
| 벨 | 밀사 | 시대 3 | 은밀한 서신 → 관계 대상 1명 |

- 신뢰: 퀘스트 완수 +10, 소속 세력 평판 상승 +2, 대화 +3(주 소모 없음)

- 의뢰인은 마을 실내에 상주한다. 찾아가야 만난다 — 관계 대상과 반대다

## 8. 대화 시스템

이 게임의 얼굴이다. UI 품질을 여기에 집중한다.

### 8.1 레이아웃

```
┌─────────────────────────┐
│  (필드가 흐리게 비친다)  │
│                         │
│      ┌───────────┐      │
│      │           │      │  인물 이미지
│      │  업로드    │      │  3:4, 화면폭 78%
│      │  이미지    │      │
│      └───────────┘      │
│ ┌─────────────────────┐ │
│ │[세리아]             │ │  이름표
│ │ 대사가 한 글자씩     │ │  대사창
│ │ 나타난다.        ▼  │ │
│ └─────────────────────┘ │
└─────────────────────────┘
```

- 필드는 지우지 않고 **어둡게 깔아둔다.** 어디서 대화 중인지가 보여야 한다
- 인물 이미지는 아래에서 14px 올라오며 페이드 인 (280ms)
- 대사는 **글자당 26ms** 타이핑. A를 누르면 즉시 전체 표시, 한 번 더 누르면 다음
- `prefers-reduced-motion`이면 타이핑 없이 즉시 표시

### 8.2 슬롯 사용 규칙

| 상황 | 사용 슬롯 |
|---|---|
| 일반 대화 | 0 (기본 초상) |
| 감정이 실린 대사 | 1 (표정 변화) — 없으면 0으로 대체 |
| 동행 탐사 화면 | 2 (전신) — 없으면 0 |
| 고백·관계 선언 | 3 (사건 삽화) 배경 전면 |
| 연인/맹우 도달 | 4 (트랙 전용) |
| 100 도달 회상 | 5 |

- **슬롯이 비어 있어도 게임은 정상 작동한다.** 상위 슬롯이 없으면 하위로, 슬롯 0도 없으면 원형 실루엣으로 폴백
- 폴백은 조용히 한다. "이미지가 없습니다" 같은 안내를 대화 중에 띄우지 않는다

### 8.3 상태 기계

```
닫힘 → 열림(타이핑) → 대기(▼) → [다음 줄 | 선택지 | 닫힘]
```

- 선택지는 대사창 아래에 세로로 쌓는다. 최대 3개
- 선택지가 뜬 상태에서 A는 아무 동작도 하지 않는다. 반드시 탭으로 고른다
- 선택 후 결과 대사 1줄 → 닫힘. 결과는 화면 상단 토스트로도 짧게 (`호감 +8`)

### 8.4 대화 사건

- 원형별 4개(tier 20/40/60/80) × 6원형 = 24개. `dialogue-events.ts` 사용
- **주사위를 굴리지 않는다.** 탐사는 판정이지만 대화는 선택이다
- 정답이 없다. 호감이 적게 오르는 선택지는 세력 평판 등 다른 것을 준다
- 판단 근거는 취향 힌트(아는 사이 20부터 노출)와 그 인물의 이전 대사다

## 9. 이미지 업로드

### 9.1 절대 규칙

**원본을 참조하지 말고 복사한다.** 플레이어는 사진첩 원본을 삭제한다. `content://` URI, `File` 핸들, 파일 경로 등 원본을 가리키는 어떤 값도 저장하지 않는다.

1. 허용 형식 PNG / JPEG / WebP, 원본 8MB 이하
2. 선택 즉시 바이트를 읽어 **WebP 재인코딩**(품질 0.85, 긴 변 기준 축소)
3. **EXIF 회전 처리 필수**: `createImageBitmap(file, { imageOrientation: 'from-image' })`. 폰 사진은 그대로 그리면 눕는다. 재인코딩 과정에서 EXIF와 GPS는 제거된다
4. 비율이 다르면 자르지 않고 `contain` + 팔레트 배경
5. `createObjectURL` 결과를 저장하지 않는다. 렌더 시 생성하고 언마운트 시 `revokeObjectURL`
6. 총 40MB 초과 시 경고 (8명 × 6슬롯 = 48장 기준)

### 9.2 갤러리에 노출되지 않아야 한다

- **PWA**: IndexedDB Blob은 파일이 아니므로 MediaStore 색인 대상이 아니다. 구조적으로 보장된다
- **APK**: `Directory.Data`에만 쓴다. 공유 저장 영역 금지. `MediaScannerConnection.scanFile()` 호출 금지. `READ_MEDIA_IMAGES` 권한 요청 금지 — **시스템 포토 피커**를 쓴다
- 내보내기 zip은 파일 관리자에 보이지만 갤러리에는 뜨지 않는다. 압축 과정에서 공유 영역에 임시 파일을 만들지 않는다

### 9.3 안내

업로드 완료 화면에 한 줄: **사진첩의 원본은 지워도 됩니다.** 오해하면 폰 저장공간을 불필요하게 점유한다.

## 10. 마을 성장

- 다음 레벨 비용 = 기본 비용 × (현재 레벨 + 1). **최대 레벨 없음**
- 인구 = 전 건물 레벨 합 = **마을 지수(power)**, 시대의 유일한 게이트
- 주간 식량 소비 = 인구 × 1. 부족하면 기근

## 11. 지역 탐사

### 지역

| ID | 이름 | 해금 | 난이도 | 능력치 | 전리품(성공) | 위험도 |
|---|---|---|---|---|---|---|
| whisper | 속삭이는 숲 | 시대 0 | 9 | 민첩 | 목 4–9, 식 3–7, 금 0–4 | 2 |
| gate | 무너진 관문 | 시대 1 | 12 | 힘 | 석 5–11, 금 3–8 | 4 |
| marsh | 재의 늪 | 시대 2 | 15 | 의지 | 식 6–14, 금 5–12 | 6 |
| peaks | 서리 봉우리 | 시대 3 | 18 | 힘 | 석 12–24, 금 10–20 | 8 |
| deep | 지하 대공동 | 시대 4 | 21 | 통찰 | 석 20–40, 금 20–40 | 10 |
| rift | 별의 균열 | 시대 5 | 25 | 의지 | 금 40–80, 유물 ×2 | 14 |

**해금 조건 = 시대 도달 + 아래 중 하나**
- 그 지역을 고향으로 둔 인물이 **동료(40)** 이상
- 또는 의뢰인 퀘스트 보상

### 탐사 진행

지역은 걸어다니는 맵이다. 목록에서 고르고 결과만 보는 방식이 아니다.

1. 마을 길목에서 지역 선택 → **1주 소모** → 지역 맵 진입
2. 맵에 **사건 노드 3~5개**가 배치된다. 밟으면 판정
3. 노드를 다 밟거나 언제든 `나가기`로 복귀
4. HP가 0이 되면 강제 복귀

**노드 구성 (지역당)**
- 전리품 노드 2~3 — 판정 후 자원
- 사건 노드 1 — 텍스트 사건, 세력 평판이나 소량 XP
- 동행 노드 0~1 — 동행자가 있을 때만 나타남. 전용 대사와 호감

### 판정 공식

```
roll   = 1d20 + stats[지역.능력치] + 탐사보너스
탐사보너스 = 추적랭크 + floor(서고레벨/2) + 동행보정 + 유물보정 + 첨탑레벨
margin = roll − 지역.난이도
```

| margin | 결과 | 전리품 | XP | 부수 |
|---|---|---|---|---|
| ≥ +8 | 대성공 | ×1.8 | ×1.5 | 유물 12%, 발견 25% |
| 0 ~ +7 | 성공 | ×1.0 | ×1.0 | 유물 4% |
| −7 ~ −1 | 실패 | ×0.35 | ×0.5 | HP −(위험도/2) |
| ≤ −8 | 위기 | 0 | ×0.25 | HP −위험도 |

- 기본 XP = 난이도 × 1.5
- HP 0 → 사망 아님. HP 1로 복귀, 다음 2주 탐사 불가, 금화 20% 손실
- 서술은 `region-text.ts`(96문장 + 동행 24문장) 사용. 새로 쓰지 않는다
- **판정은 화면에 단계적으로 노출한다.** 1d20이 돌아가다 멈추고, 보정값이 하나씩 더해지고, 난이도 선을 넘는지 보여준다

### 동행

- 주당 1명. 동료(40) 이상만
- 원형 보정(§7.2) 적용, 동행 노드 해금
- **위기 결과 시 동행자가 부상** — 4주간 동행·대화 불가, 호감 −8

| 시트 | 64×96, 캐릭터당 PNG 1장 |
| 프레임 | **16×24**, `spacing: 0`, `margin: 0` |
| 배열 | 4열 × 4행 = 16프레임 |
| 행 순서 | **0=아래, 1=왼쪽, 2=위, 3=오른쪽** |
| 걷기 | 4프레임 `0→1→2→3` 순환. 프레임 1·3이 동일한 정지 자세, 0·2가 좌우 발 |
| 정지 | 프레임 1 |
| 색 | 8색 + 투명 |

- 상수는 `src/data/characters.ts`에 있다. **Kenney 타일셋은 `spacing: 1`, 캐릭터 팩은 `spacing: 0`이다. 값을 공유하지 말 것**
- 한 칸 이동 140ms에 `WALK_FPS = 8`이면 한 걸음에 4프레임이 대략 들어간다
- **투명 픽셀이 마젠타(255,0,255)에 알파 0으로 저장돼 있다.** 알파를 평탄화하는 변환을 거치면 마젠타가 드러난다. 리사이즈·아틀라스 작업에서 알파를 반드시 보존할 것

**팔레트 충돌과 해결 (중요)**

캐릭터 팩은 메가드라이브풍 밝은 파스텔 8색이다(머리 `#FFFF92`, 외곽선 `#000048`, 옷 `#2092DB`). v1의 차분한 흙색 세계 팔레트에 그대로 얹으면 **캐릭터가 배경에 붙은 스티커처럼 뜬다.**

- **캐릭터를 리맵하지 않는다.** 16px에 8색뿐이라 뭉개지고, 15종이 공유하는 통일 팔레트라는 최대 장점이 사라진다
- 대신 **세계 32색의 명도·채도를 올려** 캐릭터 쪽에 맞췄다. 갱신된 값은 `src/data/palette.ts` v2
- 팔레트는 **세계 32색 + 캐릭터 8색 = 40색**으로 확정. `CHAR` 그룹은 수정 금지
- 계절 틴트는 캐릭터 레이어에 **절반 강도**로만 적용한다(`CHAR_TINT_SCALE = 0.5`). 100%로 걸면 인물이 배경과 함께 물들어 안 읽힌다

**배역 배정 (15종)**

| 스프라이트 | 배역 |
|---|---|
| 1 | 플레이어 |
| 2–9 | 관계 대상 8명 (원형별로 배정, 같은 원형이 둘이면 다른 스프라이트) |
| 10–15 | 의뢰인 6명 |

### 팔레트

`src/data/palette.ts`의 **40색(세계 32 + 캐릭터 8)만** 사용한다. Tailwind 기본 팔레트를 쓰지 않는다 — 맵과 UI의 색온도가 어긋난다.

- 외부 타일셋은 `scripts/remap-palette.ts`로 이 팔레트에 맞춘다
- **캐릭터 팩은 10색 고정 팔레트다.** 리맵하면 픽셀 수가 적어 뭉갤 수 있다. 먼저 리맵 없이 넣어보고 색이 겉돌면 그때 팔레트에 10색을 편입시키는 쪽을 택한다. 리맵을 강행하지 않는다
- 일러스트는 리맵 대상이 아니다. `public/assets/illustration/`으로 분리

### 성능

- 목표 중급 안드로이드 60fps
- 동시 스프라이트 300개 이하
- 타일·캐릭터는 텍스처 아틀라스로 묶는다
- 초기 번들 1.5MB 이하(폰트 제외). 폰트는 서브셋 후 굵기당 300~400KB

## 13. 시대 · 붕괴 · 끝없음

### 시대

| 시대 | 이름 | 필요 power |
|---|---|---|
| 0 | 개척기 | 0 |
| 1 | 정착기 | 6 |
| 2 | 성장기 | 14 |
| 3 | 영주기 | 26 |
| 4 | 왕국기 | 42 |
| 5 | 전설기 | 62 |
| 6 | 신화기 | 90 |

power ≥ 90 이후 `eraTier = floor((power − 90) / 30) + 1` 로 `신화기 II, III …` 무한히 이어진다. 티어마다 지역 위험도 +10%, 전리품 +10%.

### 붕괴

**조건**: 식량 0 미만이 4주 연속 + 인구 3 이하

| 대상 | 처리 |
|---|---|
| 건물 | 초기화. 회관 Lv1만 |
| 자원 | 0. 재건 지원 목재 20·식량 20 |
| 시대 | 1단계만 하락 |
| 캐릭터 레벨·능력치 | 유지 |
| 스킬 | 랭크 절반 회수 후 SP 환급 |
| 유물 | 절반 유실 |
| 관계 대상 | 호감 절반 하락. 벗(60) 미만은 떠남(레코드 보존) |
| **업로드 이미지** | **100% 보존. 예외 없음** |
| 연대기·갤러리 | 보존 |

- 붕괴 1회당 시대 임계값 5% 완화 (재기 보정)
- 연대기에 `제2대 아쉬베일`로 세대가 기록된다
- **냉정함은 예고 없음이 아니라 되돌리기 어려움이다.** 식량이 마이너스 되는 주부터 경고 배너, 2주 전 문어체 경고, 직전 1주에 유물을 팔아 시간을 사는 거래 선택지 1회

### 끝나지 않는 이유

1. 건물 최대 레벨 없음 → power 무한 → 시대 무한
2. 관계 대상 8명이 차도 떠나보내고 새로 받을 수 있다
3. 스킬 48랭크 이후 초월 랭크(초과 랭크마다 비용 +1 SP 누진)
4. 연대기가 계속 쌓인다 — 이것이 실질적 보상이다

## 14. 저장·배포

### 저장

- 상태 `localStorage`, 이미지 `IndexedDB`, 둘 다 **`StorageAdapter` 뒤에 격리**. 게임 코드에서 직접 호출 금지
- **원장(ledger)**: 세이브와 별도 키. `maxTurnReached`, `collapses`, `lastCollapseTurn`. 불러오기가 값을 낮추지 못한다. 붕괴 이전 시점의 세이브를 불러오면 즉시 붕괴가 재적용된다
- `schemaVersion` 마이그레이션 체인. **실패 시 덮어쓰지 말고** 원본을 백업 키로 보존하고 오류 표시
- 자동 저장: 주 종료 시 + 건설·관계 변화 직후 + 맵 전환 시
- 꾸러미 내보내기/불러오기 zip: `save.json` + `images/companion_{id}_slot_{n}.webp` + `ledger.json`. **양방향 이전을 M5에서 검증한다**

### 지속성 (안드로이드)

- Safari 7일 삭제는 **비적용**(iOS 전용). 안드로이드는 선제 삭제하지 않는다
- `navigator.storage.persist()` 요청이 주력
- PWA 설치 유도 — WebAPK로 런처에 등록되고 지속 모드 승인 가능성이 오른다
- **File System Access API는 안드로이드 미지원.** 폴더 자동 백업 불가 → 공유 시트로 zip 전달
- 마지막 내보내기 후 20주 경과 시 비강제 배너

### 배포

- **1순위: 정적 호스팅(GitHub Pages) + PWA 설치.** 빌드 도구·키스토어 불필요, 업데이트 자동
- **선택: Capacitor APK.** 브라우저 데이터 삭제에도 안전. `StorageAdapter` 교체로 전환. `INTERNET` 권한 제거로 비통신을 구조적으로 보장. 키스토어 분실 시 업데이트 불가 — 백업이 세이브 보호와 동일 우선순위
- **배포 주소를 바꾸기 전에 꾸러미를 내보낸다.** 출처가 바뀌면 세이브가 따라오지 않는다

### 비통신

- CDN 참조 금지, 분석·크래시 리포팅 금지, 외부 API 금지
- 검증: 비행기 모드 전 기능 플레이 / DevTools 네트워크 탭 0 / 번들에서 `http://` `https://` 문자열 검색
